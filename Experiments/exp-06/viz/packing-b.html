Packing B at any N

Parent (a, b) is centred on child (N·a, N·b); a child belongs to the nearest parent centre by d² = dq² + dq·dr + dr², ties to the lexicographically greatest (a, b). Exp-03 and exp-05 use N = 6, 60 and 36. Drag N and watch the battlements.

Tints are the seven parents nearest the centre; the heavy outlines are their ideal hexagons, which the owned territory follows with battlement edges. The centre parent's owned cells are counted live.

owner(c, N):
    (a, b) near (q/N, r/N), the 3×3 candidates round it
    d² = dq² + dq·dr + dr²   with (dq, dr) = (q − N·a, r − N·b)     // hex distance squared, integer
    smallest d² wins; a tie goes to the greatest (a, b)

every parent owns exactly N² children, for any N: all parents are alike under translation,
and there is one parent per N² children on average, so each owns N² exactly

corner children split three ways only when 3 | N: the parent's corner is at N·(2/3, −1/3, −1/3),
a child centre when N is a multiple of 3, a child corner otherwise
edge children are halved for every N: the edge midpoint N/2·e is a child centre (N even) or a
half-integer offset whose line still runs through child centres in every other row (N odd)
