# Fonts

`NotoSansJP-Regular.otf` — Noto Sans JP, Regular, the Japanese subset from
[notofonts/noto-cjk](https://github.com/notofonts/noto-cjk) (`Sans/SubsetOTF/JP/`).

Not made for this repository: it is © The Noto Project Authors and licensed under the
SIL Open Font License 1.1, in `OFL.txt` beside it. Neither the repository's MIT licence
nor its CC BY-SA asset licence applies to it.

The UI's font. It covers Latin as well as Japanese, so one font serves both catalogues
and text keeps its shape when the language changes. Bevy's built-in font has no Japanese
glyphs at all.
